# RobFlow Session Clipper

A Chrome extension that automatically copies the RobFlow virtual robot session URL to your clipboard.

## Install

### Quick install (recommended)

1. Download `robflow-session-clipper.crx`
2. Open `chrome://extensions` in Chrome
3. Enable **Developer mode** (top-right toggle)
4. Drag and drop the `.crx` file onto the page
5. Click **Add extension**

Developer mode can be turned off again after installing.

### Load unpacked (for development)

1. Clone or download this repo
2. Open `chrome://extensions`
3. Enable **Developer mode**
4. Click **Load unpacked** and select the repo folder

## Usage

Navigate to a RobFlow session at `robco.studio/cloud-robflow`. The extension icon will appear in your toolbar — click it to copy the session URL to your clipboard.
